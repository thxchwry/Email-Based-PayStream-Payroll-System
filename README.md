# Email-Based PayStream Payroll System 📧 

ระบบ RPA (Robotic Process Automation) ขนาดเล็กที่พัฒนาด้วยภาษา Python สำหรับช่วยอำนวยความสะดวกในการจัดการและส่งสลิปเงินเดือนพนักงานในรูปแบบ PDF ที่มีการเข้ารหัสลับ และส่งตรงไปยังอีเมลของพนักงานแต่ละคนโดยอัตโนมัติ

---

## ✨ ฟีเจอร์หลัก (Key Features)

*   **📄 Automated PDF Generation**: สร้างไฟล์สลิปเงินเดือน (Pay Advice) รูปแบบ PDF ที่สวยงามและเป็นมืออาชีพโดยอัตโนมัติ
*   **🔐 PDF Encryption**: เข้ารหัสไฟล์ PDF ด้วยรหัสผ่าน (ใช้รหัสผ่านจากวันเริ่มงานของพนักงาน) เพื่อความปลอดภัยสูงสุดของข้อมูลส่วนบุคคล
*   **📧 Gmail Integration**: เชื่อมต่อกับ Gmail API เพื่อส่งอีเมลพร้อมแนบไฟล์สลิปไปยังอีเมลพนักงานโดยตรง
*   **📂 Organized Storage**: ระบบจัดเก็บไฟล์ที่แยกตามปี และสร้างโฟลเดอร์รายบุคคลให้อัตโนมัติ ง่ายต่อการตรวจสอบย้อนหลัง
*   **📊 Excel Data Processing**: อ่านข้อมูลรายชื่อพนักงาน เงินเดือน และรายละเอียดต่างๆ จากไฟล์ Excel โดยตรง

---

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

*   **Python**: ภาษาหลักที่ใช้ในการพัฒนา
*   **fpdf2**: สำหรับออกแบบและสร้างไฟล์ PDF
*   **ezgmail**: สำหรับจัดการการส่งอีเมลผ่าน Gmail API
*   **pikepdf**: สำหรับการเข้ารหัสและจัดการความปลอดภัยของไฟล์ PDF
*   **openpyxl**: สำหรับการอ่านและจัดการข้อมูลจากไฟล์ Excel (.xlsx)
